# PHP Code Challenges 💻

This repository contains two beginner-level PHP code challenges designed to test basic understanding of PHP syntax, forms, and logic handling.

## 🔧 Challenges Overview

### ✅ Code Challenge 1: Registration Form

Create a registration form that:

- Accepts user inputs (e.g., name, email, password)
- Validates all fields (non-empty, valid email format, minimum password length)
- Displays error messages if validation fails
- Displays a personalized welcome message upon successful registration

📌 Example:

```

Welcome, John Doe! Your email [john@example.com](mailto:john@example.com) has been registered successfully.

```

🛠 Files:  
- registration.php  
- style.css (optional for basic styling)

---

### ➕ Code Challenge 2: PHP Calculator

Build a simple calculator that:

- Accepts two numeric inputs
- Accepts a mathematical operation: +, -, ×, or ÷
- Validates that the inputs are numbers and the operator is valid
- Returns and displays the result
- Handles divide-by-zero errors gracefully

📌 Example:

```

Inputs: 12, 4, "/"
Result: 3

```

🛠 Files:  
- calculator.php

---

## 🛠️ Technologies Used

- PHP 8+
- HTML/CSS
- Basic form validation
- Minimal JavaScript (optional)

---

## 🧪 Running the Challenges

1. Ensure PHP is installed locally (or use XAMPP/WAMP/Laragon).
2. Place the challenge files in your web server directory (e.g., htdocs for XAMPP).
3. Access them in your browser:

   - Registration: http://localhost/registration.php  
   - Calculator: http://localhost/calculator.php
